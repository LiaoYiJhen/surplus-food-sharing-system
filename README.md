# Surplus Food Sharing System｜剩食共享系統

剩食共享系統是一個以「減少食物浪費」為核心的 Web 應用程式，
透過數位平台媒合仍可食用的剩餘食物與有需求的使用者，
讓即將被浪費的食物能在變質之前找到需要它的人。

## Project Motivation｜專案目的

日常生活中，商家在營業結束前可能仍有未售完的食品，
會議、聚會或活動結束後也可能留下仍可食用的餐點。
這些食物本身仍具有食用價值，卻可能因缺乏即時的資訊傳遞管道而被丟棄。

因此，本專案開發「剩食共享系統」，
希望建立剩食提供者（Provider）與領取者（Recipient）之間的資訊媒合平台。

提供者可以將過剩或未售完、但仍可食用的食品刊登至平台；
領取者則可以透過定位功能搜尋附近目前可取得的剩食，
降低剩食資訊與實際需求之間的落差。

系統本身不介入實際領取與交易過程，
而是專注於提供即時的剩食資訊與地理位置媒合，
協助使用者快速了解「哪裡有剩食可以取得」。

## User Roles｜使用者角色

### Provider｜剩食提供者
適用於具有剩餘食品的商家、活動單位或其他使用者。

提供者可以：
- 註冊與登入系統
- 刊登剩食資訊
- 設定品項、數量、價格與折扣
- 更新剩食剩餘數量

### Recipient｜剩食領取者
適用於有食物需求，或希望透過實際行動減少食物浪費的使用者。

領取者可以：
- 註冊與登入系統
- 開啟裝置定位
- 搜尋附近可取得的剩食
- 查看剩食與提供者資訊

## Core Features｜核心功能

- 🔐 會員註冊與登入
- 👤 Provider / Recipient 角色管理
- 🥡 剩食刊登與數量更新
- 📍 使用者即時定位
- 🔎 鄰近剩食搜尋
- 🗺️ 地址與經緯度轉換
- 🔑 JWT 身分驗證
- 🗄️ PostgreSQL 關聯式資料庫

## Project Goal｜專案目標

本專案希望透過資訊系統建立一個簡單且即時的剩食媒合機制，
讓提供者能快速發布剩餘食品資訊，
並讓領取者依據目前位置尋找鄰近剩食。

藉由結合 Web 開發、資料庫與地理位置服務，
將「減少食物浪費」的概念轉化為可實際操作的資訊系統。
